🎨 Custom Design

The CREATE YOUR OWN DESIGN button opens a page where customers upload pictures, place them on the print area, preview the mug and add it to the cart. After payment you receive the print file and the preview (JPG) in the order.

This version of the site is not connected to the server, so the design page is switched off here (the design files need the server).

Mug colors and photos used for the preview

Each color needs at least one photo of that mug (a blank mug, like the examples). The customer's design is placed on the photo. Add photos for the 11 oz mug, and for the 15 oz mug if it looks different. For every photo choose which side of the mug it shows, then click Adjust if the design does not sit right on the mug.

Where do the design files go?

Only after a customer pays, the print file and the preview (both JPG) are uploaded to your Supabase storage. The order email and the order card in the Orders tab contain download links. Run the file supabase_designs_setup.sql once in the Supabase SQL Editor before using this feature.

Your settings (texts, images, prices, variants, discounts, reviews, wallets...) are saved inside this browser. If browser data is cleared or you switch browser or computer, they disappear. Download a backup file and keep it somewhere safe (email it to yourself or put it in Google Drive). 2. Make your settings apply to every visitor

                    
Settings you change in this panel (prices, texts, variants, discounts, wallet addresses, PayPal Client ID, the email key) are saved in this browser only. To publish them: click the button and copy the code. Then open the HTML file, press Ctrl+F and search for PUBLISHED SETTINGS START. Replace everything from that line down to the matching PUBLISHED SETTINGS END line with the copied code (the copied code already includes both lines), and upload the file again. Repeat whenever you change settings.

                    
                    
                    
                    
Not included: your orders and your admin password (the two password lines are in the Password tab) or your PayPal email. Everything that is included becomes visible to anyone who views the page source: wallet addresses, PayPal Client ID and the email Access Key.
